# 交易行助手与模块独占机制设计方案

> 状态：暂缓实施。本文档仅保存设计方案，当前项目中不包含对应功能实现。

## Summary

- 新增顶层“交易行助手”模块，拥有独立配置、模板、坐标、热键、日志和运行状态。
- 顶部页签切换即模块激活：切换时立即停止其他模块的运行、测试、采集、延时事件和专属热键；隐藏到托盘不算切换。
- 每次运行只执行一次购买，完成后清理全部运行事件，但保留配置，可手动再次开始。

## Key Changes

### 模块独占协调

- 新增后端权威的 `Workspace` 协调器，包含宏、游戏录制、Buff、交易行及两个计算器。
- 用 `activate_workspace` 取代单纯的托盘菜单切换：
  - 同页签重复点击不停止当前任务。
  - 切换页签时停止所有旧模块活动并使旧线程、重连和延时回调失效。
  - 清除宏坐标录制、按键编辑和交易坐标采集状态。
  - 游戏回放输入释放失败时拒绝切换，页面保持原模块，全局紧急停止仍可用。
  - 成功后才更新前端页面、托盘菜单和模块热键。
- 全局只常驻 `Ctrl+Alt+Esc` 紧急停止；其余仅注册当前模块热键。
- 宏、游戏和交易模块允许使用相同热键，只校验模块内部重复及紧急停止冲突。
- 所有启动、配置和热键回调在 Rust 端再次校验当前激活模块，防止旧回调越权执行。

### 交易行配置

- 独立存储到应用数据目录下的 `trade-assistant/`，不与 Buff 配置或模板混用。
- 配置包含：
  - 目标游戏窗口、搜索区域、商品模板和遮罩。
  - 刷新、商品、购买三个绝对物理屏幕坐标。
  - 采集、开始、停止三个独立热键，默认分别为 `Ctrl+Alt+Q/P/O`。
  - 0–10 秒可配置启动倒计时，默认 3 秒。
  - 坐标采集时记录目标窗口物理边界；窗口移动或缩放后阻止启动并要求重新采集。
- 坐标采集流程为：选择槽位 → 切回游戏 → 按采集热键。采集点必须位于已配置的目标窗口内。
- 如果重新采集时窗口边界已变化，更新参考边界并清空另外两个旧坐标，避免混用失效坐标。

### 图像识别与购买状态机

- 抽取 Buff 助手中通用的窗口枚举、截图、区域裁剪、模板遮罩、灰度匹配和稳定帧检测能力；Buff 与交易模块保留各自独立状态机和存储。
- 前端复用并通用化现有图片配置向导：
  1. 选择游戏窗口并捕获预览。
  2. 框选商品列表搜索区域。
  3. 裁剪目标商品图像。
  4. 可选涂抹动态数字、价格或闪光区域。
  5. 实时查看置信度并测试模板。
- 第一版固定使用 95% 阈值、连续 3 帧确认、连续 5 帧判定消失。
- 单一串行运行线程负责全部时序，避免刷新与购买竞态：
  1. 启动图像监听并进入配置的倒计时，倒计时期间不执行点击。
  2. 倒计时结束后，若商品已确认出现则直接购买；否则 1 秒后首次刷新。
  3. 后续每次成功刷新至少间隔 1000ms，不在暂停恢复后补发积压点击。
  4. 首次确认商品出现后原子取消刷新，停止后续刷新点击。
  5. 点击商品坐标，等待至少 500ms，再点击购买坐标。
  6. 购买点击成功注入后进入 `completed`，停止截图、重连、刷新和延时任务。
- 游戏不在前台时暂停所有点击但继续识别；回到前台且窗口位置、大小仍匹配后自动恢复。
- 如果在商品点击与购买点击之间失去焦点，保留尚未执行的购买步骤，恢复后继续，不重复商品点击。
- 手动停止、切换模块或紧急停止发生在 500ms 等待期间时，购买点击必须被取消。
- 截图中断时暂停并尝试重新连接；窗口边界变化、点击注入失败或模板处理失败时停止并进入错误状态。

### 前端与公开接口

- 新增 `tradeAssistant` 工作区和“交易行助手”页面，包含运行控制、配置完整性、坐标采集、热键与倒计时、图像向导、识别测试及日志。
- 六个顶部页签在窄窗口下改为两行布局，避免挤压品牌、更新和主题按钮。
- 交易模块激活时，托盘提供“开始抢购/停止抢购”。
- 新增 Rust/TypeScript 类型：
  - `TradeAssistantConfig`
  - `TradeCoordinates` / `TradeCoordinateSlot`
  - `TradeAssistantHotkeys`
  - `TradeAssistantActivity`
  - `TradeAssistantState`
- 新增命令覆盖状态读取、模板配置/测试、坐标采集、设置保存、开始和停止；新增 state、metric、execution-log 事件。
- 安装更新阻断逻辑加入交易倒计时、监听、暂停、购买和模板测试状态。

## Test Plan

- 验证切换每个模块都会停止旧模块任务、注销旧热键，并拒绝已排队的旧回调。
- 验证紧急停止覆盖宏录制/执行、游戏录制/回放、Buff 监控/测试和交易全部阶段。
- 验证倒计时、首次刷新、1000ms 刷新间隔、3 帧确认、500ms 购买延时及仅购买一次。
- 验证识别后不再发生刷新；停止或切页期间不会执行待定购买点击。
- 验证前台焦点暂停/恢复、窗口关闭重连、窗口移动后拒绝点击。
- 验证负坐标、100%/125%/150% 缩放和混合 DPI 多显示器。
- 验证完成和错误状态均清理运行资源，但购买完成后保留模板、坐标和设置。
- 补充交易页面/controller、六页签导航、安装阻断及共享图像编辑组件回归测试。
- 依次运行前端测试与构建、Rust `fmt/check/clippy`，最后验证 Tauri Windows 构建，避免并行运行重型检查。

## Assumptions

- 第一版以两次鼠标输入成功注入作为“购买完成”，不识别“已售出、余额不足、购买失败”等结果，也不自动重试。
- 坐标采用用户选择的绝对屏幕坐标；窗口移动或缩放必须重新采集。
- 不主动抢占或切换游戏焦点，只暂停并等待用户返回。
- 本次不更新版本号、不打标签、不执行正式发布。
